# AUDIO GELA · Portal general

Portal de entrada a las distintas aulas de AUDIO GELA.

## Estado actual

- **2.º ESO · 2026/27:** disponible y enlazado con su aula.
- **4.º ESO · 2026/27:** visible como «En preparación».

## Publicación en GitHub Pages

1. Crear un repositorio público llamado `audiogela`.
2. Subir todos los archivos de esta carpeta a la raíz del repositorio.
3. En **Settings → Pages**, seleccionar **Deploy from a branch**.
4. Elegir la rama `main` y la carpeta `/ (root)`.
5. Guardar. El portal quedará publicado en:

   `https://xtronzio.github.io/audiogela/`

## Activar 4.º ESO

Cuando exista su web, editar `index.html`, sustituir el bloque desactivado de 4.º ESO por un enlace con la clase `button` y colocar su dirección pública en el atributo `href`.

## Archivos

- `index.html`: portal completo.
- `logo-audiogela.png`: logotipo utilizado en la cabecera.
- `favicon.png`: icono del navegador.
- `apple-touch-icon.png`: icono para dispositivos Apple.
- `.nojekyll`: indica a GitHub Pages que publique los archivos directamente.
